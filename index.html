This page is a simulation of an eve session, in pure HTML/CSS/JS. The run is scripted, but the mechanics are real: every step maps to a file in agent/, progress is checkpointed after each phase (state persists in localStorage, so a crash or a closed tab resumes cleanly), subagents work in parallel, and the website the agent writes into its sandbox actually renders — the artifact is genuine. In production, eve runs this on Vercel Workflows with Vercel Sandbox. vercel.com/eve · github.com/vercel/eve
